## About

The price of a product can change soon after you buy it—and a “big discount” doesn’t always mean it’s the best price.

**Amazon CashBack** helps you keep an eye on prices and make more informed shopping decisions. Track products, review price history, and get notified when prices change.

## Features

- **Price history** — See how a current offer compares with past prices.
- **Price-drop alerts** — Set a target price and get notified when an item reaches it.
- **Offer comparison** — Compare offers across Amazon and other marketplaces.
- **Post-purchase tracking** — Keep tracking an item after you buy it and check whether compensation may be available if its price drops.

## Get started

1. Install the tool.
2. Shop as usual and add products you want to follow.
3. Set a target price, if available.
4. Get notified about price changes.

> Features and availability may vary by product, marketplace, and region. Check the website for current details.
